# 最小协作实验执行约定

用户于 2026-09-05 授权开始实验、并行可独立工作。本目录实现已保存计划的 A0→A1→A2 首包；旧实验目录、旧评分数据、旧准入文件和历史结果保持原样。

## 本轮范围与顺序

1. A0：离线协议检查，任务公开检查，真实容器生命周期，官方基线与参考补丁资格。这里的参考补丁只进入独立评分流程，不能给候选模型看。
2. A1：固定 Astropy 14995、xarray 7229，每题 S/L/R2/D/T，合计 10 次模型实验。真实选择器核验与选择、D 单测试者和 T 双 worker 路径必须有观测；普通解题失败仍保留，基础设施或账目不明会停止。
3. A2：只有同版本 A1 合格才运行；预先抽定 16 题、11 仓库，每题五策略，共 80 次。先完成逐题环境资格，不使用跑题后的难度或结果换题。
4. A2 只产生开发集候选与淘汰决定，不声称独立确认机制有效。本轮不会自动追加 H/M/R/G 或可选机制验证菜单。

## 并行与资源

本机 Docker 约 15.21 GiB 内存；一次接纳一个完整实验，预留最多 3 个候选容器（各 3 GB）和 4 个模型调用位置。R2 双候选以及团队 worker 在实验内部并行；候选全部退出且清理确认后，评分串行运行。新控制器批次间互斥不约束旧控制器，因此启动前另核查旧实验已停止。

## 冻结的资源合同

每次实验 600,000 token 准入预算、28 次工作调用、12 次 CM 调用（token 共池），推理期限 1,800 秒。CLI 输出量只能用于预约，不能声称硬性截断；实际超额会记账并阻止继续接纳。未知用量保留预约，并停止新实验。

R2 两候选分别固定 270,000 token / 12 工作调用 / 6 CM，选择器固定 60,000 / 4 / 0；不可借用。选择器只能读取原补丁、读取公开证据、执行冻结公开检查并按 ID/hash 选原补丁。

阶段 dispatch 截止为 A1 9 小时、A2 61 小时，不新增超额 episode。采用冻结历史价格情景计算 API 等价费用：A1 USD 40 提醒、60 停止新增；A2 USD 320 提醒、480 停止新增。阈值在当前实验结算后检查，不是供应商硬扣费上限。价目观察日为 2026-09-04，汇率为历史固定输入，不代表当前报价或订阅实际账单。实际现金费用不可观测则标未知；不得把未知当零。

## 证据与推进

运行代码、测试证据、公开输入、镜像 ID、评分合同和非密钥传输执行器身份冻结。正式进程从 runtime_snapshot 导入代码；凭据仅通过环境传递。每次调用保留模型/角色/effort/请求与报告 tier、时间、输入/缓存/输出/推理 token、原始响应与账本票据；总费用逐次只加一次。

官方解题结果、补丁/执行完整性、用量完整性、费用可算性分开记录。所有失败和 fallback 均保留；未知费用不否定已确认的代码正确性，但不能据此声称省钱。S* 并列且任一并列策略成本未知时跳过整个成本排序层。五臂须同一组 16 个唯一任务，先逐一判断 D/T 资格，再选 C*。补充约束：S* 为 0/16 时，不能凭更便宜的 0/16 失败取得经济性晋级。

STOP 只停止接纳新实验，当前实验收束；CANCEL 或超时需终止本实验进程树并核查其容器所有权和实际退出。未完成清理、未知账目、补丁哈希变化或评分环境失败都阻止继续；原补丁评分基础设施失败最多重试一次。每个批次保留 manifest、逐次结果、调用明细、状态和中文报告。
