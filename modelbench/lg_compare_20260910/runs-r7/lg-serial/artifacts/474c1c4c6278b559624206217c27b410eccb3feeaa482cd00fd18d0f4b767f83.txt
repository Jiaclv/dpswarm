【子任务 A · 修订交付（修复 req-0：删除第五字段 items）】

```json
{
  "$schema": "http://json-schema.org/draft-07/schema#",
  "title": "MiniBookkeepingRecord",
  "type": "object",
  "properties": {
    "id": { "type": "string" },
    "amount": { "type": "number", "multipleOf": 0.01 },
    "currency": { "type": "string", "pattern": "^[A-Z]{3}$" },
    "tags": { "type": ["array", "null"], "items": { "type": "string" } }
  },
  "required": ["id", "amount", "currency", "tags"],
  "additionalProperties": false
}
```

设计说明：
1. 修复项：properties 与 required 两处中的第五字段 items 已一并删除、零残留；required 恰为原文四字段，与 additionalProperties:false 自洽——仅按四字段构造的合法记录必通过校验。
2. tags 可空语义（显式声明，供下游逐字引用）：选用「允许 null」——tags 取 null 合法；非 null 时必须为数组且元素全为 string（元素个数不作要求）。
3. 澄清：tags 内部的 `items` 是 JSON Schema 的数组元素约束关键字，非记录字段，不属于本次删除的残留。
4. amount 的两位小数以 multipleOf 0.01 表达；实现校验建议用 Decimal(str(x)) % Decimal("0.01") == 0 或换算整数分比较，规避二进制浮点取模误差。
5. currency 以 pattern "^[A-Z]{3}$" 约束为大写三字母（ISO 4217 风格）；id 仅约束 type: string，未附加额外条件，与原文一致。
6. $schema 声明 draft-07，type 数组、items、additionalProperties 均为该版标准关键字，下游校验器按同版语义实现即可。
