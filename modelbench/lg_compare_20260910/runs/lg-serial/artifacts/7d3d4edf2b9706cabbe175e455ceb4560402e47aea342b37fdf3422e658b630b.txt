```json
{
  "$schema": "http://json-schema.org/draft-07/schema#",
  "title": "BookkeepingRecord",
  "type": "object",
  "required": ["id", "amount", "currency"],
  "properties": {
    "id": {
      "type": "string",
      "minLength": 1
    },
    "amount": {
      "type": "number",
      "multipleOf": 0.01
    },
    "currency": {
      "type": "string",
      "pattern": "^[A-Z]{3}$"
    },
    "tags": {
      "type": ["array", "null"],
      "items": { "type": "string" },
      "uniqueItems": true
    }
  },
  "additionalProperties": false
}
```

**设计说明**
1. 基于 draft-07；`id/amount/currency` 必填，`tags` 允许缺省或传 `null`（`type: ["array","null"]`）。
2. `amount` 用 `multipleOf: 0.01` 约束两位小数；如需限定非负可自行加 `minimum: 0`。
3. `currency` 用正则 `^[A-Z]{3}$` 对齐 ISO 4217 形式（如 CNY、USD）。
4. `id` 设 `minLength: 1` 防空串；`tags` 元素须为字符串且 `uniqueItems` 去重。
5. `additionalProperties: false` 拒绝未定义字段，保证结构严格。
6. 注意：`multipleOf` 依赖浮点实现，极端精度场景建议应用层配合十进制库二次校验。
