```json
{
  "$schema": "https://json-schema.org/draft/2020-12/schema",
  "$id": "https://example.com/schemas/ledger-record.json",
  "title": "LedgerRecord",
  "description": "迷你记账的单条记录",
  "type": "object",
  "properties": {
    "id": {
      "type": "string",
      "minLength": 1,
      "description": "记录唯一标识"
    },
    "amount": {
      "type": "number",
      "multipleOf": 0.01,
      "description": "金额，精确到两位小数"
    },
    "currency": {
      "type": "string",
      "pattern": "^[A-Z]{3}$",
      "description": "ISO 4217 三字母货币代码"
    },
    "tags": {
      "type": "array",
      "items": { "type": "string", "minLength": 1 },
      "default": [],
      "description": "分类标签，可为空数组"
    }
  },
  "required": ["id", "amount", "currency"],
  "additionalProperties": false
}
```

设计说明：

1. 采用 draft 2020-12；`tags` 用 `default: []` 表达"可空"（空数组语义），未列入 `required`，允许缺省。
2. `amount` 用 `multipleOf: 0.01` 约束两位小数，避免字符串格式化与数值类型冲突。
3. `currency` 用正则 `^[A-Z]{3}$` 做结构校验；ISO 4217 全集枚举太长，交由应用层校验有效性。
4. `additionalProperties: false` 防止冗余字段混入，保证记录结构稳定。
