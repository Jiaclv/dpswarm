```json
{
  "$schema": "https://json-schema.org/draft/2020-12/schema",
  "$id": "https://example.com/schemas/mini-ledger-record.json",
  "title": "MiniLedgerRecord",
  "description": "迷你记账记录",
  "type": "object",
  "properties": {
    "id": {
      "type": "string",
      "minLength": 1
    },
    "amount": {
      "type": "number",
      "multipleOf": 0.01,
      "minimum": 0
    },
    "currency": {
      "type": "string",
      "pattern": "^[A-Z]{3}$"
    },
    "tags": {
      "type": ["array", "null"],
      "items": { "type": "string" },
      "uniqueItems": true
    }
  },
  "required": ["id", "amount", "currency", "tags"],
  "additionalProperties": false
}
```

设计说明：
1. `amount` 用 `multipleOf: 0.01` 约束两位小数，并设 `minimum: 0` 排除负金额。
2. `currency` 用 `^[A-Z]{3}$` 正则限定 ISO 4217 三字母大写代码。
3. `tags` 允许 `null`（type 数组写法），元素为字符串且去重。
4. 四个字段均列入 `required`，`tags` 可传 `[]` 或 `null`。
5. `additionalProperties: false` 收紧结构，防止冗余字段混入。
6. 采用 2020-12 草案，`multipleOf` 对浮点数在部分校验器中可能有精度问题，若环境不支持可改用 `pattern` 配合字符串类型。
