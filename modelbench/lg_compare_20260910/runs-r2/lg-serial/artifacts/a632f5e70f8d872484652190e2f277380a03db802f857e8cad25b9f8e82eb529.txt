```json
{
  "$schema": "https://json-schema.org/draft/2020-12/schema",
  "$id": "https://example.com/schemas/expense-record.json",
  "title": "ExpenseRecord",
  "description": "迷你记账记录",
  "type": "object",
  "properties": {
    "id": {
      "type": "string",
      "minLength": 1,
      "description": "记录唯一标识"
    },
    "amount": {
      "type": "number",
      "multipleOf": 0.01,
      "exclusiveMinimum": 0,
      "description": "金额，保留两位小数"
    },
    "currency": {
      "type": "string",
      "pattern": "^[A-Z]{3}$",
      "description": "ISO 4217 三字母货币代码"
    },
    "tags": {
      "type": ["array", "null"],
      "items": { "type": "string" },
      "description": "标签，可为空"
    }
  },
  "required": ["id", "amount", "currency", "tags"],
  "additionalProperties": false
}
```

设计说明：
1. `amount` 用 `multipleOf: 0.01` 约束两位小数（浮点精度限制下建议序列化时四舍五入）。
2. `exclusiveMinimum: 0` 排除零及负数金额；如需允许支出/收入双向，可移除。
3. `currency` 用正则 `^[A-Z]{3}$` 保证大写三字母格式，符合 ISO 4217。
4. `tags` 通过 `type: ["array", "null"]` 允许 null，但仍在 `required` 中强制字段存在（区分“缺失”与“显式为空”）。
5. `additionalProperties: false` 禁止多余字段，保证记录结构严格。
6. 采用 2020-12 草案，包含 `$id` 便于复用引用。
