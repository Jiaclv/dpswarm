```json
{
  "$schema": "https://json-schema.org/draft/2020-12/schema",
  "$id": "https://example.com/schemas/mini-ledger-record.json",
  "title": "MiniLedgerRecord",
  "type": "object",
  "required": ["id", "amount", "currency"],
  "properties": {
    "id": { "type": "string", "minLength": 1 },
    "amount": {
      "type": "number",
      "multipleOf": 0.01
    },
    "currency": {
      "type": "string",
      "pattern": "^[A-Z]{3}$"
    },
    "tags": {
      "type": ["array", "null"],
      "items": { "type": "string", "minLength": 1 },
      "uniqueItems": true
    }
  },
  "additionalProperties": false
}
```

设计说明：
1. `id` 必填、非空字符串，作为记录唯一标识。
2. `amount` 用 `multipleOf: 0.01` 约束到两位小数；正负均可，允许记账冲销。
3. `currency` 用正则限定为三个大写字母，符合 ISO 4217 形式（值域校验留给业务层）。
4. `tags` 类型声明为 `["array", "null"]` 实现“可空”，元素为非空字符串且去重。
5. `required` 不含 `tags`，即允许缺省；出现时可为 null 或数组。
6. `additionalProperties: false` 收紧结构，防止脏字段混入。
