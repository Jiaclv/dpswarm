已定决定（材料设计说明）：
- id / amount / currency / tags 四字段全部列入 `required`；`additionalProperties: false` 拒绝未知字段，目的是使 B 阶段校验逻辑简单确定。
- `amount`：`multipleOf: 0.01` 约束两位小数；`minimum: 0` 排除负金额。
- `currency`：pattern `^[A-Z]{3}$`，即三字母大写 ISO 4217 代码。
- `tags`：通过 `oneOf` 同时接受 `null` 与字符串数组，满足"可空"要求。
- `id`：`minLength: 1`，避免空字符串充当合法主键。
- 固定 `$id` 与 draft 2020-12，便于 B 逐字引用与后续复用。
