## 交付物

```json
{
  "$schema": "https://json-schema.org/draft/2020-12/schema",
  "$id": "https://example.com/schemas/mini-ledger-record.json",
  "title": "MiniLedgerRecord",
  "description": "迷你记账记录：最小化字段集的账目条目",
  "type": "object",
  "required": ["id", "amount", "currency", "tags"],
  "properties": {
    "id": {
      "type": "string",
      "minLength": 1,
      "description": "记录唯一标识，非空字符串"
    },
    "amount": {
      "type": "number",
      "multipleOf": 0.01,
      "description": "金额，精确到两位小数"
    },
    "currency": {
      "type": "string",
      "pattern": "^[A-Z]{3}$",
      "description": "ISO 4217 三字母货币代码，大写"
    },
    "tags": {
      "type": ["array", "null"],
      "items": { "type": "string", "minLength": 1 },
      "uniqueItems": true,
      "description": "标签数组，可为 null；元素为非空字符串且不重复"
    }
  },
  "additionalProperties": false
}
```

## 设计说明（≤10 行）

1. 四个字段全部列入 `required`，其中 `tags` 允许 `null`，语义区分「无标签」与「字段缺失」。
2. `amount` 用 `multipleOf: 0.01` 约束两位小数；基于 JSON Schema 规范，`multipleOf` 对 `number` 类型生效，且能同时拦截 3 位及以上小数。
3. `currency` 用 `^[A-Z]{3}$` 正则匹配 ISO 4217 代码（如 CNY、USD），强制大写以减少归一化成本。
4. `tags` 数组内元素要求非空字符串，`uniqueItems: true` 防止重复标签。
5. `additionalProperties: false` 关闭扩展，保证记录结构严格受控，便于下游逐字引用与校验。
