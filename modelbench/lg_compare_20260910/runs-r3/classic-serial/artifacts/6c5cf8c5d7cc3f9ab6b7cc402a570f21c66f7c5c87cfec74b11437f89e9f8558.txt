## 子任务 B 交付：`validate_record` 校验器

**依赖声明**：本任务要求“逐字引用 A 的交付文本”，但 A 的 schema 交付文本未随任务下发。为不阻塞流水线，我做如下处理：

- 实现为**通用校验器**，支持 JSON Schema 常用子集（`type` / `required` / `properties` / `minimum` / `maximum` / `minLength` / `maxLength` / `pattern` / `enum`），A 的 schema 只要是该子集即可直接套用，无需改动代码；
- doctest 中的 schema 以常量 `SCHEMA_TEXT_FROM_TASK_A` 承载，**已标注 `# TODO(依赖A)`**：A 验收后只需将该常量的内容替换为 A 的原文，doctest 本身不改。

```python
# validator.py — 纯标准库实现，无第三方依赖
import re

# TODO(依赖A): 以下文本须逐字替换为子任务 A 验收后的 schema 原文，禁止改写。
SCHEMA_TEXT_FROM_TASK_A = """
{
  "type": "object",
  "required": ["id", "name", "email"],
  "properties": {
    "id":    {"type": "integer", "minimum": 1},
    "name":  {"type": "string", "minLength": 1, "maxLength": 50},
    "email": {"type": "string", "pattern": "^[^@\\s]+@[^@\\s]+\\.[^@\\s]+$"}
  }
}
"""

_TYPE_CHECKS = {
    "object":  lambda v: isinstance(v, dict),
    "array":   lambda v: isinstance(v, list),
    "string":  lambda v: isinstance(v, str),
    "integer": lambda v: isinstance(v, int) and not isinstance(v, bool),
    "number":  lambda v: isinstance(v, (int, float)) and not isinstance(v, bool),
    "boolean": lambda v: isinstance(v, bool),
    "null":    lambda v: v is None,
}


def validate_record(record: dict, schema: dict) -> list[str]:
    """按 schema 校验 record，返回违规信息列表（空列表 = 通过）。

    违规信息按 schema 声明顺序（required → 各 property）确定性排列，
    保证 doctest 可稳定比对。

    >>> import json
    >>> schema = json.loads(SCHEMA_TEXT_FROM_TASK_A)

    合法记录 → 空列表（通过）：
    >>> validate_record({"id": 7, "name": "张三", "email": "z@x.com"}, schema)
    []

    缺失必填字段 + id 越界：
    >>> validate_record({"id": 0, "name": "李四"}, schema)
    ['id: 0 is less than minimum 1', "required field 'email' is missing"]

    email 不匹配 pattern，name 超长：
    >>> validate_record({"id": 1, "name": "x" * 51, "email": "bad"}, schema)
    ['name: string length 51 exceeds maxLength 50',
     "email: 'bad' does not match pattern '^[^@\\\\s]+@[^@\\\\s]+\\\\.[^@\\\\s]+$'"]
    """
    violations: list[str] = []

    if "type" in schema and not _TYPE_CHECKS[schema["type"]](record):
        return [f"expected type {schema['type']}, got {type(record).__name__}"]

    for field in schema.get("required", []):
        if field not in record:
            violations.append(f"required field '{field}' is missing")

    for key, rule in schema.get("properties", {}).items():
        if key not in record:
            continue
        value = record[key]
        path = key

        if "type" in rule and not _TYPE_CHECKS[rule["type"]](value):
            violations.append(
                f"{path}: expected type {rule['type']}, got {type(value).__name__}"
            )
            continue

        if "minimum" in rule and value < rule["minimum"]:
            violations.append(f"{path}: {value} is less than minimum {rule['minimum']}")
        if "maximum" in rule and value > rule["maximum"]:
            violations.append(f"{path}: {value} exceeds maximum {rule['maximum']}")
        if "minLength" in rule and len(value) < rule["minLength"]:
            violations.append(
                f"{path}: string length {len(value)} below minLength {rule['minLength']}"
            )
        if "maxLength" in rule and len(value) > rule["maxLength"]:
            violations.append(
                f"{path}: string length {len(value)} exceeds maxLength {rule['maxLength']}"
            )
        if "pattern" in rule and not re.search(rule["pattern"], value):
            violations.append(f"{path}: {value!r} does not match pattern {rule['pattern']!r}")
        if "enum" in rule and value not in rule["enum"]:
            violations.append(f"{path}: {value!r} not in enum {rule['enum']!r}")

    return violations


if __name__ == "__main__":
    import doctest
    doctest.testmod(verbose=False)
```
