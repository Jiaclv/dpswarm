```json
{
  "$schema": "https://json-schema.org/draft/2020-12/schema",
  "$id": "https://example.com/schemas/mini-ledger-entry.json",
  "title": "迷你记账记录",
  "type": "object",
  "properties": {
    "id": { "type": "string" },
    "amount": {
      "type": "number",
      "multipleOf": 0.01
    },
    "currency": {
      "type": "string",
      "pattern": "^[A-Z]{3}$"
    },
    "tags": {
      "type": ["array", "null"],
      "items": { "type": "string" }
    }
  },
  "required": ["id", "amount", "currency", "tags"],
  "additionalProperties": false
}
```

设计说明（9 行内）：
1. `id` 为普通字符串，未限定格式，交由上层系统约束（如 UUID）。
2. `amount` 用 `multipleOf: 0.01` 约束两位小数精度。
3. `currency` 用正则 `^[A-Z]{3}$` 保证大写三字母代码（ISO 4217 形式）。
4. `tags` 允许 `null` 或字符串数组，元素均为字符串。
5. 四个字段全部 `required`，含 `tags`（必须显式出现，可为 null）。
6. `additionalProperties: false` 拒绝未定义字段，保证结构稳定。
7. 采用 JSON Schema Draft 2020-12，验证工具兼容性最佳。
