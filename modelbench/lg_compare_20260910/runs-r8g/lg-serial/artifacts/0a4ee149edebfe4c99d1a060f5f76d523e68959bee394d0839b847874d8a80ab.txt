```json
{
  "$schema": "https://json-schema.org/draft/2020-12/schema",
  "title": "迷你记账记录",
  "type": "object",
  "properties": {
    "id": { "type": "string" },
    "amount": { "type": "number", "multipleOf": 0.01 },
    "currency": { "type": "string", "pattern": "^[A-Z]{3}$" },
    "tags": { "type": "array", "items": { "type": "string" } }
  },
  "required": ["id", "amount", "currency", "tags"],
  "additionalProperties": false
}
```

设计说明（5 行，≤10 行合规）：
1. `id` 为记录唯一标识，类型 string，必填。
2. `amount` 为金额，类型 number，`multipleOf: 0.01` 约束两位小数精度。
3. `currency` 为货币代码，string 类型，`pattern: ^[A-Z]{3}$` 约束三字母大写代码。
4. `tags` 为标签数组，元素均为 string；JSON Schema 原生允许数组留空/缺省，配合 required 四字段满足「可空」语义。
5. 四字段全部列入 `required`，`additionalProperties: false` 封闭结构，便于 B 步校验器按确定性规则实现。
