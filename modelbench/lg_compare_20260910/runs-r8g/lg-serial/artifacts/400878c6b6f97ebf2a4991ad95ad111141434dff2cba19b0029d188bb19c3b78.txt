```json
{
  "$schema": "https://json-schema.org/draft/2020-12/schema",
  "$id": "https://example.com/schemas/mini-ledger-record.json",
  "title": "MiniLedgerRecord",
  "type": "object",
  "properties": {
    "id": {
      "type": "string",
      "description": "记录唯一标识"
    },
    "amount": {
      "type": "number",
      "multipleOf": 0.01,
      "description": "金额，精确到两位小数"
    },
    "currency": {
      "type": "string",
      "pattern": "^[A-Z]{3}$",
      "description": "ISO 4217 三字母货币代码"
    },
    "tags": {
      "type": "array",
      "items": { "type": "string" },
      "description": "标签列表，可为空数组"
    }
  },
  "required": ["id", "amount", "currency", "tags"],
  "additionalProperties": false
}
```

**设计说明（≤10 行）：**

1. `amount` 用 `multipleOf: 0.01` 约束两位小数精度；
2. `currency` 用正则 `^[A-Z]{3}$` 锁定大写三字母代码；
3. `tags` 为字符串数组，`items` 限定元素类型，空数组合法（可空）；
4. 四个字段全部 `required`，`additionalProperties: false` 保证结构封闭；
5. 采用 draft 2020-12，附 `$id` 便于子任务 B 引用与复用。
