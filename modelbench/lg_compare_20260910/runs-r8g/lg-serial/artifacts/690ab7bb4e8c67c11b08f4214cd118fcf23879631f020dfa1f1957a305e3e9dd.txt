```json
{
  "$schema": "https://json-schema.org/draft/2020-12/schema",
  "title": "Mini Accounting Record",
  "type": "object",
  "additionalProperties": false,
  "required": ["id", "amount", "currency", "tags"],
  "properties": {
    "id": {
      "type": "string"
    },
    "amount": {
      "type": "number",
      "multipleOf": 0.01
    },
    "currency": {
      "type": "string",
      "pattern": "^[A-Z]{3}$"
    },
    "tags": {
      "type": ["array", "null"],
      "items": {
        "type": "string"
      }
    }
  }
}
```

设计说明：
1. 4 个字段均为必填，且禁止额外字段。
2. `amount` 为数值，并用 `multipleOf: 0.01` 限制金额精度到分。
3. `currency` 必须是大写三字母代码。
4. `tags` 可为字符串数组或 `null`，空数组也允许。
