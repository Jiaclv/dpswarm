## 交付内容（子任务 A：schema 设计）

```json
{
  "$schema": "https://json-schema.org/draft/2020-12/schema",
  "title": "MiniLedgerRecord",
  "type": "object",
  "properties": {
    "id": { "type": "string" },
    "amount": { "type": "number", "multipleOf": 0.01 },
    "currency": { "type": "string", "pattern": "^[A-Z]{3}$" },
    "tags": { "type": ["array", "null"], "items": { "type": "string" } }
  },
  "required": ["id", "amount", "currency", "tags"],
  "additionalProperties": false
}
```

设计说明：
1. id 仅约束为字符串类型，不限定格式，便于子任务 B 做纯类型校验；
2. amount 用 `multipleOf: 0.01` 表达"两位小数"约束，校验器可按浮点余差实现；
3. currency 用正则 `^[A-Z]{3}$` 强制三字母大写代码（如 CNY/USD）；
4. tags 允许字符串数组或 null（"可空"用 `["array","null"]` 表达），元素必须为字符串；
5. 四字段全部 required，且 `additionalProperties: false` 关闭未声明字段，保证 B 的校验器逻辑封闭可判定。
