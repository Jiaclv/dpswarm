## 设计说明（7 行，≤10）

1. 顶层 type=object，四个字段 id / amount / currency / tags 均为必填（required）。
2. id：纯字符串，业务唯一性由调用方保证，schema 层不加约束。
3. amount：type=number，multipleOf=0.01 将数值限制在两位小数（JSON 数字不保留尾随零，故用倍数约束而非格式约束）。
4. currency：type=string，pattern ^[A-Z]{3}$ 限定三字母大写代码（ISO 4217 风格）。
5. tags：type=["array","null"]，即「字符串数组、可空」；数组元素 items 均为字符串。
6. 仅使用 draft 2020-12 基础关键字（type / required / pattern / multipleOf / items），B 用纯标准库可逐条映射实现。
7. 上述 JSON 块为 B 的唯一引用源，B 的 doctest 中 schema 必须与其逐字一致。
