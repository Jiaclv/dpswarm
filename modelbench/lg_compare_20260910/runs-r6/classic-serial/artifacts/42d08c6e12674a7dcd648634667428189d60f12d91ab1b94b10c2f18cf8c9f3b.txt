### 依据 schema（wi-cc8152c306 交付，逐字引用）

```json
{
  "type": "object",
  "properties": {
    "id": {"type": "string", "minLength": 1},
    "amount": {"type": "number", "multipleOf": 0.01},
    "currency": {"type": "string", "pattern": "^[A-Z]{3}$"},
    "tags": {"type": ["array", "null"], "items": {"type": "string"}}
  },
  "required": ["id", "amount", "currency", "tags"]
}
```

### 实现

```python
import re
from decimal import Decimal


def validate_record(record: dict, schema: dict) -> list[str]:
    """校验迷你记账记录，返回违规信息列表（空列表 = 通过）。

    判定依据与已验收节点 wi-cc8152c306 的 ```json schema 块逐字一致：
    id: string/minLength；amount: number/multipleOf 0.01；
    currency: string/pattern ^[A-Z]{3}$；tags: [array, null]/items string。

    >>> schema = {
    ...     "type": "object",
    ...     "properties": {
    ...         "id": {"type": "string", "minLength": 1},
    ...         "amount": {"type": "number", "multipleOf": 0.01},
    ...         "currency": {"type": "string", "pattern": "^[A-Z]{3}$"},
    ...         "tags": {"type": ["array", "null"], "items": {"type": "string"}}
    ...     },
    ...     "required": ["id", "amount", "currency", "tags"]
    ... }
    >>> validate_record({"id": "tx-001", "amount": 12.5, "currency": "USD", "tags": ["food"]})
    []
    >>> validate_record({"id": "tx-002", "amount": 3.141, "currency": "USD", "tags": []})
    ['amount: 3.141 is not a multiple of 0.01']
    >>> validate_record({"id": "tx-003", "amount": 5.0, "currency": "usd", "tags": ["food", 1]})
    ["currency: 'usd' does not match ^[A-Z]{3}$", 'tags: element at index 1 is not a string']
    """
    violations: list[str] = []
    props = schema["properties"]

    # id: {"type": "string", "minLength": 1}
    id_value = record.get("id")
    min_len = props["id"]["minLength"]
    if not isinstance(id_value, str) or len(id_value) < min_len:
        violations.append(f"id: must be a string of minLength {min_len}")

    # amount: {"type": "number", "multipleOf": 0.01}（Decimal 规避浮点取模误差）
    amount_value = record.get("amount")
    multiple_of = props["amount"]["multipleOf"]
    if isinstance(amount_value, bool) or not isinstance(amount_value, (int, float)):
        violations.append("amount: must be a number")
    elif Decimal(str(amount_value)) % Decimal(str(multiple_of)) != 0:
        violations.append(f"amount: {amount_value} is not a multiple of {multiple_of}")

    # currency: {"type": "string", "pattern": "^[A-Z]{3}$"}
    currency_value = record.get("currency")
    pattern = props["currency"]["pattern"]
    if not isinstance(currency_value, str) or re.search(pattern, currency_value) is None:
        violations.append(f"currency: {currency_value!r} does not match {pattern}")

    # tags: {"type": ["array", "null"], "items": {"type": "string"}}
    tags_value = record.get("tags")
    tags_rule = props["tags"]
    tags_types = tags_rule["type"] if isinstance(tags_rule["type"], list) else [tags_rule["type"]]
    if tags_value is None:
        if "null" not in tags_types:
            violations.append("tags: must be array or null")
    elif isinstance(tags_value, list) and "array" in tags_types:
        item_type = tags_rule["items"]["type"]
        for index, element in enumerate(tags_value):
            if item_type == "string" and not isinstance(element, str):
                violations.append(f"tags: element at index {index} is not a string")
    else:
        violations.append("tags: must be array or null")

    return violations


if __name__ == "__main__":
    import doctest
    doctest.testmod(verbose=False)
```

### 实现要点

- **multipleOf 0.01**：`3.141 % 0.01` 直接用 float 会因二进制表示误判，故转 `Decimal(str(x))` 取模，`Decimal("3.141") % Decimal("0.01") = 0.001 ≠ 0`，正确报违规；合规值如 `12.5`、`5.0` 余数为 0。
- **pattern**：按 JSON Schema 语义用 `re.search`，schema 中模式自带 `^...$` 锚定，`'usd'` 不匹配。
- **tags 可空**：`None` 直接通过（`"null" in ["array", "null"]`）；列表则逐元素校验 `items.type == "string"`，报违规时附下标。
- **违规顺序确定**：id → amount → currency → tags，与 schema 键序一致，doctest 输出可复现。
- **排除 bool**：`isinstance(True, int)` 为真，amount 判定先行剔除布尔值。
