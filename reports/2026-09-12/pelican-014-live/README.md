## 浏览器独立复核

在 Chrome 152.0.7977.84、1200 × 800 视口实际打开相同 SHA 的文件：仅加载本地 HTML，0 外部请求、0 页面异常、0 控制台错误；人工看图可辨认鹈鹕喉囊、车架、双轮、双腿和踏板。

自然播放 3.5233 秒，两轮各转约 4.404 圈，两曲柄各转约 2.202 圈。进一步取实际 DOM 的 1.6 秒周期测量 97 个相位，轮各转 2 圈、曲柄各转 1 圈；实际腿路径端点与脚原点重合，每个采样相位脚填充区域都与踏板矩形采样点重叠。依据轮轴相对角度和实际 SVG 动画几何，而非仅对整图做像素差分。

这不是严格机械模型验证：小腿长度约 95.30–102.15 SVG 单位，源码“严格 100/100 刚性连杆”注释不成立；脚与曲柄销的固定偏移还存在约 0.65 单位的中间插值变化。围巾的一条描边未跟随身体起伏，可能产生约 3 单位错位。核心骑行动作已观察到，这两处保留为质量问题。

## 仍需要改进的 Harness 行为

以下是本轮暴露的后续改进方向，没有在这次冻结的实际执行中热改：

1. **收尾报告可靠性。** 初始三个角色都在无工具的收尾请求中输出了伪调用文本；Tester/Reviewer 明确有自然 stop 和完整 usage，不能统称“被截断”。Harness 应向 Lead 明示输出性质、实际已执行动作和报告格式状态，让 Agent 决定补报告或继续工作；不能执行报告中的伪调用。仅移除工具和增加一句提示仍不足以保证模型正确收尾。
2. **当前证据版本提示。** Tester 补报告失败也会改变验证输入，使旧 review 失效；这一保护机制工作正常。工具应更突出“旧报告可解析，但已过期”、失效原因和当前合法动作，避免 Lead 将接管误称共签并多走两个错误请求。
3. **验证能力与结论边界。** 提供当前浏览器可用性、模型是否可读图以及实际尝试结果，由 Agent 选择 DOM、数值、视觉验证或声明 unknown。不能把静态检查自动提升成已观察渲染，也不能为所有任务写死浏览器步骤。
4. **需求来源和范围。** Lead 将原一句用户请求扩为具体配色、围巾、翅膀、传动与严格运动学要求。宜显式区分用户硬要求和 Agent 的实现选择，由 Agent 判断投入与充分性，避免自行扩展后再花大量预算验证自加约束。

本案例验收恢复与预算账本已闭环；自动测试角色的有效产出、语义验证质量和总消耗仍需要进一步改进，不能据单例推断通用成功率或效率提升。
