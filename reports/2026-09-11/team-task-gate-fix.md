## 系统提示估算边界

原生宿主的 pre-step 和 agent/request 钩子均早于 system prompt projection。此时公开 API 尚未给出下一请求采用“替换系统提示”还是“追加系统提示”的信息，不能简单减掉已有提示，否则追加模式会被低估。

修复采用同一规则处理 TokenMeter 补价与 JSON 请求估算：保留会话中的历史系统提示；当前 rendered 提示与最后有效系统提示相同则不重复补价；没有现存提示或提示变化则加入新提示的估算。变化后实际走替换模式时，该值是保守上界，不声称是精确计数。系统提示变化时不得复用旧请求的实测 usage 锚。
