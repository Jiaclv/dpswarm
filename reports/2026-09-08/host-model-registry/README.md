# 0.7.3：固定团队直接使用 DPH 模型注册服务

此前，一个模型即使能在 DPH 主对话中使用，也可能因为没有 DPSwarm／AA 目录条目而收到 `MODEL_UNAVAILABLE`。0.7.3 让固定团队直接使用 DPH 后端的精确模型解析服务；模型只需在 DPH 配置一次。

## 行为

- 实现者默认继承当前 Lead 请求的 Provider、模型与推理强度；也可手动指定。
- 团队启动和每次角色派发前核对路由，不以界面目录是否列出或 AA 是否评分作为门槛。
- Provider 被移除、路由或推理强度不再有效时，停止新派发并返回原因，不静默换模型；既有交付仍能验收。
- 宿主投影与会话绑定并持久保存。未知价格与能力保持未知；固定 B／2 点是运营占位，不能据此推断模型能力或开放动态裂变。
- 团队与 CM 仍是独立开关，Reviewer 默认由 Lead 承担。预检不生成回复，也不证明服务商额度充足。

## 本机可选设置：关闭 skill-catalog

`skill-catalog` 是 DPH 内置 `tool-skill` 发布的技能目录消息，并非独立安装的 skill 包。本机按用户要求，在标准、代码、创造模式的本地 preset 副本中禁用该工具；技能文件与历史消息保留。实际 preset 内容和已挂载插件状态已核验，未通过新增模型请求读取最终工具 schema。

这项设置属于宿主偏好，不改变 DPSwarm 默认设置。当前 DSH 0.1.1-rc.2 会固定原有 roster 的根目录，因此本机配置禁用原 roster，并以不同配置 ID 挂载同一 preset 服务、优先读取本地副本。宿主升级后应对照新版 preset 更新副本；本机路径、账户配置不在公开仓库中发布。
